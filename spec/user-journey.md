## 二、关键场景详解

### 场景 A：首次使用 → 首次出题（0→1 激活）

```
时间线：15 分钟

1. 下载项目（2 min）
   → git clone + 双击 start.bat
   → 系统自动检测 Python + 安装依赖
   → 浏览器打开 http://localhost:5050

2. 配置 API Key（3 min）
   → 复制 .env.example → .env
   → 填入 DeepSeek API Key
   → 重启服务

3. 导入第一篇笔记（5 min）
   → 打开 Dashboard → 粘贴一段 Lenny 播客摘要
   → LLM 自动结构化为 Markdown 笔记
   → 点击"确认入库"（draft → ready）

4. 首次出题（3 min）
   → 点击"生成测验" → 输入 topic
   → 5 道题生成（~8s）
   → 4 道通过 QA Gate
   → 开始答题

5. 首次评分（2 min）
   → 提交答案 → LLM 评分
   → 得分 80%，2 道错题
   → 错题自动生成错题卡 + SM-2 安排复习
   → 看到六维雷达图

🎯 Aha Moment：用户意识到"我不用自己出题，AI 帮我出了，还能告诉我哪里弱"
```

### 场景 B：日常学习循环（Day 2-30）

```
每周日晚上（30 min）：
  1. 导入本周收藏的 3-5 篇文章/播客笔记（10 min）
  2. 逐篇审核（verify），确保内容准确（5 min）
  3. 针对本周学习主题出题（5 min）
  4. 答题 + 查看评分 + 看雷达变化（10 min）

每天通勤/碎片时间（5 min）：
  1. 打开错题本，系统自动提醒今天该复习的错题
  2. 重新作答
  3. SM-2 更新间隔（连续答对 → 间隔拉长）
```

### 场景 C：面试前的突击复习（Day 60）

```
面试前 3 天：
  1. 查看六维雷达 → 发现"商业化思维"维度最低（45%）
  2. 筛选该维度相关笔记 → 批量出题
  3. 集中刷题 → 错题 > 60% 自动入 SM-2 循环
  4. 面试前再看雷达 → 72%（提升 27%）
  5. 面试时被问"你怎么理解 AI 产品的定价策略" → 对答如流
```

## 三、用户情绪曲线

```
😊 高 │         🤩首次出题
     │        ╱
     │  😤配置 ╱
     │   ╲  ╱
     │    ╲╱
─────┼───────────────────── 😊日常使用（稳定的正反馈）
     │
     │              📈持续成长（雷达分提升）
     │
😟 低 │  安装门槛（一次性）
     └──────────────────────────────────────────→ 时间
        Day 0    Day 1    Day 7    Day 30   Day 60
```

**关键洞察**：安装门槛是唯一负向时刻。后续每一个触点都是正向反馈（出题惊喜 → 评分启发 → 成长可见）。

## 四、流失风险点

| 阶段 | 风险 | 缓解措施 |
|------|------|---------|
| 安装配置 | API Key 配置失败 → 放弃 | start.bat 自动检测 + 交互式引导 + 详细错误提示 |
| 首次出题 | 出题质量差 → 失望 | QA Gate ≥ 3/5 门禁 + 人工 verify 保障笔记质量 |
| Day 7-14 | 新鲜感消退 → 不再打开 | SM-2 到期待复习提醒（计划中） |
| Day 30+ | 笔记太多管理困难 | P2 语义检索（触发条件：笔记 > 500） |

## 五、与 Anki 的旅程对比

| 环节 | Anki | Knowledge Lab |
|------|------|------|
| 内容准备 | 手动制卡（30 min/篇） | 粘贴 → AI 结构化（5 min/篇） |
| 出题 | 卡片即题目（单一题型） | AI 生成单选/简答/场景（3 种题型） |
| 评分 | 自评 0-3 分（主观） | LLM 自动评分 + 详细反馈（客观） |
| 能力评估 | 无 | 六维雷达图 |
| 复习调度 | SM-2（经典） | SM-2（同算法） |

> 核心差异：Anki 解决"怎么复习"，Knowledge Lab 解决"怎么出题 + 怎么复习 + 怎么知道自己哪里弱"。
