# Knowledge Lab · Product Requirements Document

> 版本：v0.1 · 2026-07-27 · 状态：MVP 已上线

---

## 一、问题定义

### 1.1 核心问题

**自学 AI PM 的人有三个痛点：**

1. **学了很多，不知道记住多少** — 看书、听播客、刷文章，被动输入了大量信息，但缺乏主动回忆机制，留存率低
2. **不知道自己薄弱在哪** — 没有客观的能力评估，不知道自己哪个维度弱，复习方向靠感觉
3. **不知道如何规划学习路径** — 自学没有老师指导，不知道从哪开始、先学什么后学什么、怎么判断自己是否真的进步了。被动输入时感觉"学了很多"，但一到面试或实战就暴露知识盲区

### 1.2 现有方案的不足

| 现有方案 | 问题 |
|---------|------|
| Anki | 需要手动制卡，无 AI 辅助，无能力评估 |
| Notion/Obsidian | 笔记工具，无测验功能，无间隔重复 |
| Dify/Quivr | Chat-First（被动问答），无 Quiz-First（主动回忆），无学习闭环 |
| 刷题 App | 题库固定，无法用自己的学习材料出题 |

### 1.3 一句话定位

> **Knowledge Lab = Anki 的 SM-2 算法 × Obsidian 的笔记生态 × LLM 的自动出题 × 六维能力评估**

把"做卡 30 分钟 + 复习 10 分钟"变成"导入笔记 → 自动出题 → AI 判题 → 看雷达图"的零门槛 AI 学习闭环。

## 二、目标用户

### Persona 1：转行 AI PM 的自学者 · 小明

- 背景：2 年传统 PM，想转 AI PM，自学了 6 个月
- 痛点：看了 50+ 篇文章和 20+ 期播客，但不记得具体内容
- 场景：每天通勤听 Lenny's Podcast，周末用 Knowledge Lab 把播客笔记导入 → 出题自测 → 发现"商业化思维"维度最弱 → 针对性补
- 目标：3 个月内达到 AI PM 面试水平

### Persona 2：AI PM 从业者 · Lisa

- 背景：已经在做 AI PM，需要持续学习跟上领域发展
- 痛点：行业变化太快（每月新模型/新范式），碎片化知识难以体系化
- 场景：每周导入 3-5 篇行业文章，用 Knowledge Lab 自动出题验证理解，能力雷达追踪成长
- 目标：保持行业前沿，构建系统化知识体系

### Persona 3：培训机构/课程讲师 · 老王

- 背景：AI PM 培训课程讲师
- 痛点：需要为学员提供自测工具，但手动出题工作量巨大
- 场景：将课程讲义导入 Knowledge Lab → 批量生成测验题 → 学员自测 + 自动评分 → 讲师查看班级能力分布
- 目标：降低出题成本 90%，提升学员学习效果

## 三、核心功能

### P0 · MVP（已实现）

| 功能 | 说明 | 对应端点 |
|------|------|---------|
| **内容导入** | URL/YouTube/粘贴文本 → LLM 结构化 → Markdown 笔记 | POST /notes/import, /notes/paste |
| **自动出题** | 扫描 Vault → RAG 组装 Prompt → LLM 生成题目 → QA 门禁 | POST /quiz/generate |
| **智能评分** | LLM 批改 → SM-2 错题调度 → 错题卡生成 | POST /quiz/grade |
| **能力雷达** | 六维评估（AI技术/评测/数据/产品/商业/工程） | GET /competency |
| **知识库管理** | 笔记浏览/审核/删除 + 草稿管理 | GET /notes, /notes/drafts |

### P1 · 近期计划

| 功能 | 说明 |
|------|------|
| **多模型评测** | 跨 5 个 LLM 的出题质量/速度/成本横向对比 |
| **缓存优化** | 同题不重复调 API，延迟 < 50ms |
| **调用统计** | LLM 调用仪表盘（次数/延迟/Token/成本） |

### P2 · 远期规划

| 功能 | 触发条件 |
|------|---------|
| **语义检索** | 笔记 > 500 篇且关键词检索不够时 |
| **移动端** | 有移动端自测需求时 |
| **多用户** | 培训场景需要时 |

## 四、成功指标

| 指标 | 目标 | 测量方式 |
|------|:--:|------|
| 核心出题流程完成率 | > 95% | stats.py 错误率监控 |
| 出题质量（QA Gate 通过率） | > 85% | L0-003 自动化检查 |
| 重复出题缓存命中率 | > 30% | cache.py 命中率统计 |
| 单次出题成本 | < $0.001 | stats.py × pricing.yaml |
| 笔记→出题端到端时间 | < 15s | stats.py latency_ms |

## 五、不做什么（明确边界）

| 不做 | 原因 |
|------|------|
| 多租户架构 | 当前是个人学习工具，非 SaaS 产品 |
| 社交/社区功能 | 聚焦学习闭环，不做内容社区 |
| 移动端 App | Web 端先验证 PMF，移动端 P2 |
| AI 生成学习内容 | 只出题不生成——内容由用户自己的笔记提供（避免幻觉污染） |
| 商业化定价 | 当前免费开源，商业化时再评估 |
