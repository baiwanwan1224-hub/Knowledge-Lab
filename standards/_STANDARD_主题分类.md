# _STANDARD_主题分类.md · L0-005

> 笔记主题分类标准 · 15 个主题类别 · 用于 LLM 自动分类 + 出题标签匹配
> 维护人：AI Team · 最后更新：2026-07-29

---

## 一、分类原则

1. **基于内容，不基于标题** — 笔记标题可能误导，必须读内容再分类
2. **多标签** — 单篇笔记可属于多个主题（通常 1-3 个）
3. **宁可多标** — 不确定时放宽，出题时才需要精确筛选
4. **每季度校准** — 根据笔记库增长情况调整类别定义

## 二、15 个主题类别

### 1. AI Agent & 架构
- **描述**: AI Agent 系统架构、多 Agent 协作、工具调用、记忆系统、上下文管理、Agent 设计模式
- **关键词**: Agent, 架构, 上下文工程, tool calling, memory, orchestration, 工作流
- **示例**: "AI Agent 上下文工程的五层架构"、"Multi-Agent 协作模式设计"

### 2. LLM & Prompt 工程
- **描述**: 大语言模型原理、Prompt 设计与优化、提示链、Few-shot、CoT、模型选择与对比
- **关键词**: Prompt, LLM, token, 提示词, 思维链, few-shot, temperature, 模型对比
- **示例**: "Prompt Engineering 系统化方法论"、"Chain-of-Thought 的七种变体"

### 3. RAG & 检索系统
- **描述**: 检索增强生成、向量数据库、Embedding、语义搜索、文档分块、HyDE、重排序
- **关键词**: RAG, 向量检索, embedding, 知识库, chunking, 语义搜索, retrieval
- **示例**: "RAG Pipeline 优化实践"、"Chunking 策略对比"

### 4. AI 产品设计
- **描述**: AI 产品 UX 设计、人机交互模式、AI 原生交互、原型设计、产品思维
- **关键词**: UX, 交互设计, 原型, AI Native, 产品设计, HMI, 用户体验
- **示例**: "AI 原生 UX 设计原则"、"AI 辅助原型设计方法"

### 5. AI 评测 & 质量
- **描述**: AI 系统评测方法、基准测试、质量门禁、A/B 测试、性能评估、LLM-as-Judge
- **关键词**: 评测, eval, benchmark, QA, 质量, 测试, 准确率, 召回率
- **示例**: "AI 产品评估方法"、"LLM-as-Judge 评测框架"

### 6. 数据驱动决策

### 8. 增长 & 发布

## 三、分类流程

### 导入时自动分类

```
笔记内容 → Embedding (DeepSeek) → Top-5 候选主题
    → DS 分类: "这篇笔记属于哪些主题？" → topics_ds
    → M3 审核: "审核分类结果，是否遗漏？" → topics_m3
    → 合并去重 → 写入 frontmatter topics: [...]
```

### 出题时标签匹配

```
用户选择主题 "AI Agent & 架构"
    → find_notes() 扫描所有笔记
    → 匹配 frontmatter topics 列表
    → 返回匹配的笔记 → 出题
```
