## 一、题型评分 Rubric

### 1.1 单选题 (single_choice)

| 维度 | 标准 |
|------|------|
| 满分 | 1.0 分 |
| 判定逻辑 | 选项标签（A/B/C/D）完全匹配 `correct_answer` |
| 正确得分 | 1.0 |
| 错误得分 | 0 |
| 反馈要求 | 解释正确选项为什么对 + 学生选的选项为什么错 |

### 1.2 简答题 (short_answer)

| 分数 | 等级 | 判定标准 | 必须要素 |
|------|------|---------|---------|
| 5 | 优秀 | 全面准确，含具体案例或深度理解 | 核心概念 + 关键机制 + 实践案例 |
| 4 | 良好 | 覆盖核心要点，表述清晰 | 核心概念 + 大部分关键机制 |
| 3 | 及格 | 大部分正确，但存在显著缺漏 | 核心概念 + 部分关键机制 |
| 2 | 不足 | 只有片面理解，缺漏严重 | 有基本概念但缺失核心机制 |
| 1 | 错误 | 基本误解核心概念 | 方向错误 |
| 0 | 离题 | 完全无关或未作答 | 无 |

### 1.3 场景题 (scenario)

| 分数 | 等级 | 判定标准 | 必须要素 |
|------|------|---------|---------|
| 5 | 优秀 | 核心问题 + 结构化方案 + 利益相关者考量 | 问题识别 + 方案设计 + 利益相关者分析 |
| 4 | 良好 | 识别关键问题 + 合理方案 | 问题识别 + 方案设计 |
| 3 | 及格 | 部分理解问题，方案有可行之处 | 部分问题识别 |
| 2 | 不足 | 浅层分析，方案不完整 | 表面分析 |
| 1 | 偏题 | 理解偏差，方案不可行 | 方向错误 |
| 0 | 无关 | 完全离题 | 无 |

## 二、质量阈值

| 参数 | 值 | 说明 |
|------|-----|------|
| 及格线 | ≥ 70% 正确率 | 本次测验通过 |
| 需加强 | 40%-69% 正确率 | 建议复习相关知识点 |
| 重学 | < 40% 正确率 | 建议重新学习全部内容 |
| 错题卡触发 | 单题得分 < 60% 标准分 | 自动生成错题卡 |
| 掌握确认 | 连续 3 次正确率 ≥ 90% | 该知识点标记为已掌握 |

---

## 三、SM-2 间隔重复参数

| 参数 | 初始值 | 说明 |
|------|--------|------|
| 初始间隔 | 1 天 | 首次错误后的复习间隔 |
| 第二次间隔 | 6 天 | 第二次复习间隔 |
| 缓动因子 (ease) | 2.5 | 默认为 2.5，根据回答质量动态调整 |
| 最小缓动因子 | 1.3 | ease 下限 |
| 质量评分映射 | score/max_score × 5 | 将得分映射到 SM-2 的 0-5 质量评分 |


## 五、评分一致性保障

1. **双模型校准**：每 10 次批改随机抽取 1 次，用 GPT-4.1 独立评分，偏差 > 1 分触发审查
2. **Golden Set**：5 道金标题 + 标准答案 + 评分基准，每周回归，偏差 > 1 分调整 prompt
3. **偏差日志**：所有校准结果记录到 `_LOG_标准变更记录.md`
